# 畫面設計結果

這份文件整理 `/design` 階段的成果，供階段一做前端時使用。行為與資料規則以 `docs/architecture.md` 為準，這裡只記錄「長什麼樣子」。

- **設計稿位置**：https://claude.ai/artifact/Ds7omg6iNt1vgHPFSzDi8y （Design 畫布，7 張畫板；連結僅限本人開啟，要給別人看需從 Share 選單分享）
- **注意**：設計稿是靜態畫面，沒有互動。設計稿只存在於該連結，**沒有存進這個 repo**，所以本文件是 repo 內唯一的設計紀錄。若設計稿連結失效，以本文件為準。

## 1. 風格

簡潔、圓角、柔和配色，手機優先；淺色與深色跟隨系統設定（`prefers-color-scheme`）。（使用者在 `/design` 指令中沒有指定風格，這是依需求訪談結論決定的，可再調整。）

字型：Noto Sans TC（Google Fonts，400／500／700），後備 `system-ui, sans-serif`。

## 4. 畫板清單與對應元素

| 畫板 | 畫面 | 狀態 |
|---|---|---|
| A | 輸入代號（手機） | 重名錯誤狀態 |
| B | 聊天室（手機，淺色） | 往上捲、有新訊息 |
| C | 聊天室（手機，深色） | 線上名單展開 |
| D | 聊天室（手機，淺色） | 斷線中 |
| E | 聊天室（手機，淺色） | 空聊天室、輸入超過字數 |
| F | 聊天室（電腦，淺色） | 一般狀態 |
| G | 聊天室（電腦，深色） | 一般狀態 |

### 畫面 A：輸入代號

由上而下，置中，內容最大寬 342：

1. Logo：64×64 圓角 20 的主色方塊，白色對話框圖示
2. 標題「匿名聊天室」，28px 粗體
3. 說明「不用註冊、不用登入。取一個代號，就能和大家聊天。」
4. 標籤「你的代號」，右側字數「2 / 12」
5. 輸入框：高 52、圓角 16；錯誤時邊框改 2px 錯誤色，並設定 `aria-invalid`
6. 錯誤提示（帶圖示）：「這個代號已有人使用，請換一個」
7. 按鈕「進入聊天室」：高 52，主色，全寬
8. 底部說明：「代號為 1 到 12 個字，中文、英文、數字、表情符號都可以。」

### 畫面 B–G：聊天室

**頂部列（手機）**：左邊標題「匿名聊天室」；右邊兩個按鈕：

- 「● 線上 N 人 ⌄」膠囊按鈕（邊框、淺底），展開時箭頭向上、邊框變主色，並設定 `aria-expanded`
- 「離開」，透明底，帶登出圖示

**頂部列（電腦）**：左邊標題；右邊只有「離開」（有邊框的膠囊）。電腦不需要「線上 N 人」按鈕，因為名單常駐。

**斷線提示列**（只在斷線時出現，位於頂部列下方）：「連線中斷，重新連線中…」，帶旋轉箭頭圖示，置中，使用 `role="status"`。

**訊息區**：

- 別人的訊息：靠左；上方代號（12px 次要色）、泡泡、下方時間
- 自己的訊息：靠右、主色泡泡、不顯示代號，下方時間
- 進出提示：置中、12–13px 灰字，無背景，例如「阿傑 進來了」「小明 離開了」
- 「有新訊息 ↓」：浮在訊息區底部置中，主色膠囊、白字、帶向下箭頭、有陰影，高 44
- 空聊天室：置中顯示對話框圖示與「還沒有人說話，來打聲招呼吧」

**線上名單**：

- 標題「線上 (5)」，14px 粗體次要色
- 每列高 44：圓點＋代號，16px；自己的代號後面加「（你）」並用粗體
- 電腦：固定在右側，280 寬，白色（深色版為面板色）背景，左側邊框
- 手機：從頂部列下方浮出的圓角卡片（圓角 20、有陰影、邊框），後面蓋一層遮罩；點遮罩或再按「線上 N 人」收起

**輸入區**：

- 輸入框（多行 `textarea`）＋圓形送出鈕（紙飛機圖示）
- 手機輸入框高 44、電腦高 48；placeholder 手機「輸入訊息…」，電腦「輸入訊息，按 Enter 送出，Shift+Enter 換行」
- 超過字數：輸入框改 2px 錯誤色邊框；右上方顯示「超過 3 字（-3）」（錯誤色粗體，`role="alert"`）；送出鈕停用
- 斷線：輸入框與送出鈕停用，placeholder 改為「連線中斷，暫時無法輸入」

## 5. 圖示

全部是內嵌 SVG（描邊 2px、圓角端點、24×24 viewBox），用 `currentColor` 上色，裝飾性圖示都加 `aria-hidden="true"`。不使用 emoji 當圖示。

| 用途 | 圖示 |
|---|---|
| Logo、空聊天室 | 對話框 |
| 離開 | 登出（門與箭頭） |
| 展開／收起名單 | 向下／向上箭頭（chevron） |
| 有新訊息 | 向下箭頭 |
| 送出 | 紙飛機 |
| 斷線 | 旋轉箭頭 |
| 輸入錯誤 | 圓圈驚嘆號 |

## 6. 無障礙

- 全部用真正的 `<button>`、`<input>`、`<textarea>`、`<label>`，不用 `div` 加 `onClick`
- 純圖示按鈕加 `aria-label`（送出訊息、展開線上名單等）
- 狀態用 `aria-expanded`、`aria-invalid`、`role="status"`、`role="alert"` 標示
- 所有可點的東西高度至少 44px
- 色彩對比：文字 4.5:1。自己的訊息（白字在 `#4F5BD5` 上）約 5.5:1

## 7. 設計稿沒涵蓋、實作時需要補的

- 深色模式下的：錯誤狀態、斷線提示列、停用的輸入框與送出鈕
- 淺色模式下的：手機線上名單展開（只畫了深色版），遮罩顏色要另外決定
- 輸入代號畫面的深色版，以及「連線中」（按下進入後）的按鈕狀態
- 載入中的畫面（重新整理後自動進入聊天室、尚在連線時）
- 長訊息（無空白長字串）的換行處理、超長代號的截斷方式
- 訊息過多時，捲動區的實際行為（設計稿只是靜態畫面）
- 電腦版斷線、空聊天室、超過字數的狀態（只畫了手機版，電腦版沿用同樣元素）

## 8. 階段二之後新增的畫面元素

設計稿（第 1 到 7 節）之後新增的功能，樣式沿用上面的色彩與尺寸，不另外加新顏色。

| 元素 | 位置 | 樣式與行為 |
|---|---|---|
| **「○○ 正在輸入…」** | 訊息區與輸入框之間，一整行 | 固定高度 26px（有沒有人在輸入都一樣高，訊息區不會跳動）；字級手機 12px、電腦 13px，次要文字色（`--muted`）；單行，太長用省略號；上方有一條分隔線（原本在輸入區上緣的分隔線移到這裡）。內容：1 人「甲 正在輸入…」、2 人「甲、乙 正在輸入…」、3 人以上「N 人正在輸入…」。用 `role="status"` 與 `aria-live="polite"` |
| **輸入代號畫面的說明** | 輸入代號畫面最下方 | 原本一行說明，改成兩行：第二行「不能使用「系統」「管理員」「admin」等保留代號，也不能包含看不見的特殊字元。」樣式與第一行相同 |
| **送出失敗提示** | 輸入框上方靠右（與「超過 N 字」同一個位置與樣式） | 錯誤色粗體 13px。送太快：「送太快了，請稍等幾秒再送」；其他原因：「送出失敗，請再試一次」。輸入框的內容保留 |
| **代號錯誤提示** | 輸入代號畫面的輸入框下方（沿用原本的錯誤樣式） | 新增文字：「這個代號不能使用」（保留代號）、「代號不能包含看不見的特殊字元」 |

`?mock&debug` 的測試工具面板新增一顆「有人正在輸入」按鈕，用來在不需要第二個人的情況下看這個提示。
